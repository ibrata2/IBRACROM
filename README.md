# IBRA CROM

متصفح مبني على محرك **Chromium** مع دعم إضافات **سوق Chrome الإلكتروني** الأصلية.
برمجة و تطوير **ابراهيم الخزرجي**

## المميزات
- علامات تبويب كاملة (سحب وترتيب، كتم الصوت، إعادة فتح المغلقة، نافذة جديدة)
- تثبيت إضافات جوجل مباشرة من chromewebstore.google.com بزر «إضافة إلى Chrome»، مع أزرارها وقوائمها المنبثقة وشاراتها في شريط الأدوات وتحديثها تلقائياً
- تحميل إضافة غير مضغوطة من مجلد
- ثلاثة مظاهر: زجاجي (Acrylic حقيقي على ويندوز 11) — أبيض عادي — ليلي
- شريط عنوان ذكي مع اقتراحات البحث والسجل والإشارات
- السجل، الإشارات المرجعية (واستيرادها من كروم/Edge)، مدير تنزيلات مع إيقاف واستئناف
- البحث في الصفحة، التكبير، الطباعة، حفظ الصفحة، أدوات المطور، عارض PDF
- أذونات المواقع (كاميرا/مايك/موقع/إشعارات) مع تذكر القرار
- زر «أُغلقت مؤخراً» بجانب العلامات: كل نقرة على عنصر تعيد فتحه، واستمر بالضغط لإعادة فتح ما قبله (أو Ctrl+Shift+T)
- **IBDM Pro مدمج رسمياً**: إضافة IBDM مثبتة مع المتصفح، والتحميلات تُسلَّم مباشرة لبرنامج IBDM Pro عند تشغيله، مع خيارات «تحميل بواسطة IBDM Pro» في قائمة النقر اليمين
- تسجيل البرنامج كمتصفح في ويندوز ليمكن جعله الافتراضي

## الإصدارات
كل رفع على فرع main يبني GitHub Actions ملف التنصيب على ويندوز وينشره في صفحة Releases باسم رقم النسخة في package.json (غيّر `version` لإصدار جديد).

## البناء
```
npm install
npm start            # تشغيل للتجربة
npm run dist         # بناء ملف التنصيب dist/IBRA-CROM-Setup-x.y.z.exe
```

## الاختصارات
Ctrl+T علامة جديدة · Ctrl+W إغلاق · Ctrl+Shift+T إعادة فتح · Ctrl+L شريط العنوان · Ctrl+F بحث · Ctrl+D إشارة · Ctrl+H السجل · Ctrl+J التنزيلات · F12 أدوات المطور · F11 ملء الشاشة

## الترخيص
دعم الإضافات عبر مكتبة electron-chrome-extensions (GPL-3.0)، لذلك المشروع مرخّص GPL-3.0.
