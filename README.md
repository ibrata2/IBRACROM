# IBRA CROM

متصفح مبني على محرك **Chromium** مع دعم إضافات **سوق Chrome الإلكتروني** الأصلية.
برمجة و تطوير **ابراهيم الخزرجي**

## المميزات
- علامات تبويب كاملة (سحب وترتيب، كتم الصوت، إعادة فتح المغلقة، نافذة جديدة)
- تثبيت إضافات جوجل مباشرة من chromewebstore.google.com بزر «إضافة إلى Chrome»، مع أزرارها وقوائمها المنبثقة وشاراتها في شريط الأدوات وتحديثها تلقائياً
- تحميل إضافة غير مضغوطة من مجلد
- ثلاثة مظاهر: زجاجي (Acrylic حقيقي على ويندوز 11) — أبيض عادي — ليلي
- شريط عنوان ذكي مع اقتراحات البحث والسجل والإشارات
- السجل، الإشارات المرجعية (واستيرادها من كروم/Edge)، مدير تنزيلات مع إيقاف واستئناف
- البحث في الصفحة، التكبير، الطباعة، حفظ الصفحة، أدوات المطور، عارض PDF
- أذونات المواقع (كاميرا/مايك/موقع/إشعارات) مع تذكر القرار
- زر «أُغلقت مؤخراً» بجانب العلامات: كل نقرة على عنصر تعيد فتحه، واستمر بالضغط لإعادة فتح ما قبله (أو Ctrl+Shift+T)
- **IBDM Pro مدمج رسمياً**: إضافة IBDM مثبتة مع المتصفح، والتحميلات تُسلَّم مباشرة لبرنامج IBDM Pro عند تشغيله، مع خيارات «تحميل بواسطة IBDM Pro» في قائمة النقر اليمين
- **IBRA Proxy**: بروكسي يعمل على لسان واحد فقط (Tor مدمج مع جسور Snowflake/obfs4، أو بروكسي خاص HTTP/SOCKS) لفتح المواقع المحجوبة — يُشغّل ويُطفأ لكل لسان على حدة (Ctrl+Shift+P لسان بروكسي جديد)
- **IBRA AdBlock**: حاجب إعلانات ومتتبعات لكل المواقع (قوائم uBlock Origin و EasyList + العربية) مع عدّاد للإعلانات المحجوبة، وإيقاف لموقع معيّن أو للكل
- **IBRA Shield**: فاحص فيروسات المواقع — يوقف مواقع البرمجيات الخبيثة والتصيد والاحتيال، ويفحص الملفات المنزّلة بـ Windows Defender
- **التحكم في الوسائط** (مثل Chrome): زر في شريط الأدوات يعرض كل فيديو أو صوت يعمل في الألسن — الغلاف والعنوان، تشغيل/إيقاف، السابق/التالي، ±10 ثواني، شريط التقدم، صورة داخل صورة، والترجمة
- **كلمات السر**: حفظ تلقائي بعد تسجيل الدخول وملء تلقائي، صفحة ibra://passwords، واستيراد/تصدير CSV بصيغة Chrome (مشفّرة على الجهاز)
- تسجيل الدخول إلى حساب Google يعمل داخل المتصفح
- قائمة النقر اليمين في شريط العنوان: نسخ، لصق، لصق والانتقال
- كل الإضافات المدمجة تُشغّل وتُطفأ من صفحة الإضافات
- إضافة IBDM Pro تُؤخذ من البرنامج المثبت، أو تتحدث تلقائياً من https://github.com/ibrata2/ibdm-pro/releases — ونسخة واحدة فقط تعمل
- تسجيل البرنامج كمتصفح في ويندوز ليمكن جعله الافتراضي
- **عربي و English**: كل القوائم والصفحات بالعربية أو الإنجليزية (القائمة ← اللغة، أو الإعدادات)، وأزرار التصغير والتكبير والإغلاق دائماً على اليمين
- **إشارات حسابك في Google Chrome** تحت شريط العنوان بنفس الترتيب والمجلدات، وتتحدث تلقائياً (من Chrome المثبت على الجهاز، أو ملف HTML من Chrome / Google Takeout)
- قائمة مثل Chrome بقوائم فرعية: كلمات السر، السجل، الإشارات، المجموعات، الإضافات، البحث والتعديل، الحفظ والمشاركة، أدوات إضافية، مساعدة
- **نافذة تصفح متخفٍّ** (Ctrl+Shift+N) لا تحفظ السجل ولا الكوكيز
- **مجموعات الألسن** بالاسم واللون مع الطي والفتح
- **المساعد الذكي** في لوحة جانبية: Gemini، ChatGPT، Claude، Copilot، DeepSeek (Alt+A)
- Google Lens للصفحة وللصور، ترجمة الصفحة والنص المحدد، رمز QR للصفحة، اختصار الموقع على سطح المكتب كتطبيق
- مدير المهام (Shift+Esc)، وحذف بيانات التصفح حسب الفترة الزمنية (Ctrl+Shift+Del)

## الإصدارات
كل رفع على فرع main يبني GitHub Actions ملف التنصيب على ويندوز وينشره في صفحة Releases باسم رقم النسخة في package.json (غيّر `version` لإصدار جديد).

## البناء
```
npm install
npm start            # تشغيل للتجربة
npm run dist         # بناء ملف التنصيب dist/IBRA-CROM-Setup-x.y.z.exe
```
